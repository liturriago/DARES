Report: Mathematical Adaptation of the CREDA Loss from Classification to Image Segmentation
============================================================================================

PART I below is the base adaptation (pixel-level alignment of the CREDA estimator).
PART II is the hardened revision (CREDA-Seg v2) addressing three empirically observed
pathologies: (1) intra-class variance collapse, (2) missing inter-class repulsion,
(3) alignment-gradient domination. The hardened loss is implemented in SegCREDA.py
(same folder). All numerical claims in Part II were verified by executing the
estimator and the module (verification summary in Part II, Section 7).

============================================================================================
PART I — BASE ADAPTATION (classification CREDA -> segmentation CREDA)
============================================================================================

1. What CREDA currently computes (classification case)
Both sources define the same objective. The paper (Pérez-Rosero et al., Mathematics 2025, Eqs. 1–23) and CREDA.py implement:
Setup. Source data $\mathcal{D}_s=\{(x_i^s,y_i^s)\}_{i=1}^{N_s}$ (labeled), target data $\mathcal{D}_t=\{x_j^t\}_{j=1}^{N_t}$ (unlabeled). Feature extractor $F:\mathcal{X}\to\mathbb{R}^d$, classifier $G:\mathbb{R}^d\to[0,1]^C$. One feature vector and one probability vector per image.
Per class $c$, per mini-batch (Eqs. 15–17), Gram matrices over a Gaussian kernel $\kappa_\sigma(a,b)=\exp(-\lVert a-b\rVert^2/2\sigma^2)$, with $\sigma$ from the median heuristic (code: $\sigma=\sqrt{\operatorname{median}(d^2)}$ over the pooled class features):
$$K_c^s=[\kappa_\sigma(f_i^s,f_{i'}^s)],\qquad K_c^t=[\kappa_\sigma(f_j^t,f_{j'}^t)],\qquad K_c^{st}=[\kappa_\sigma(f_i^s,f_j^t)]$$
where source membership uses true labels and target membership uses hard pseudo-labels $\arg\max_{c'} g^t_{j,c'}=c$.
Rényi-2 entropy of a Gram matrix (Eq. 9, as coded): with the trace-normalized "density matrix" $A=K/\operatorname{tr}(K)$,
$$H_2(A)=-\log\operatorname{tr}(A^2)=-\log\lVert A\rVert_F^2$$
(the code divides by $\log 2$ to express it in bits — an irrelevant global constant for optimization).
Noise-aware weighting (Eqs. 18–20): per target sample, $\hat H_2(g_j^t)=-\log\sum_c (g_{j,c}^t)^2$, normalized uncertainty $\hat U=\hat H_2/\log C$, confidence $w_j^t=1-\hat U$, and the weighted target kernel
$$\tilde K_c^t = K_c^t \odot \big(\tilde w_c^t\,(\tilde w_c^t)^\top\big).$$
Mutual information estimator (Eqs. 21–22), using the block joint matrix that tolerates $n_c^t\neq n_c^s$:
$$\tilde I_2(K_c^s;\tilde K_c^t)=\tfrac12\big[H_2(K_c^s)+H_2(\tilde K_c^t)\big]-H_2(K_c^{mix}),\qquad K_c^{mix}=\begin{pmatrix}K_c^s & K_c^{st}\\ (K_c^{st})^\top & \tilde K_c^t\end{pmatrix}$$
Total loss (Eq. 23; the code confirms the sign convention):
$$\mathcal L_{\text{CREDA}} = \mathcal L_{\text{CE}}^s \;-\; \lambda\sum_{c}\tilde I_2\;\;=\;\;\mathcal L_{\text{CE}}^s + \lambda\,\frac{1}{|\mathcal C_{\text{valid}}|}\sum_{c}\Big(H_2(K_c^{mix})-\tfrac12\big[H_2(K_c^s)+H_2(\tilde K_c^t)\big]\Big)$$
(classes with fewer than 2 samples on either side are skipped; the code averages over valid classes rather than summing).

2. The structural difference that drives the adaptation
Classification produces one label and one feature vector per image. Segmentation produces a dense label map: for input $x\in\mathbb{R}^{H\times W\times C_{in}}$, the network yields a probability tensor $P\in[0,1]^{C\times\Omega}$ with $\sum_c P_{c,i}=1$ at every spatial location $i\in\Omega$ ($\Omega$ = pixel/voxel index set, $|\Omega|=H W$, or the feature-map resolution $h\,w$), and a feature map $\Phi(x)\in\mathbb{R}^{d\times\Omega}$ giving a per-location feature $\varphi_i\in\mathbb{R}^d$.
Every mathematical object in CREDA is built on the notion "a sample is one feature vector with one (pseudo-)label". The adaptation therefore reduces to a single decision — what is a sample in segmentation? — plus the consequences that decision propagates through the estimator.

3. Adapted formulation (pixel-level alignment, the direct generalization)
3.1 Sample space
Replace image-level features by pixel/voxel-level features. Per class $c$, per mini-batch (pooled over all images in the batch):
$$S_c=\{\varphi_i^s : y_i^s=c\},\qquad T_c=\{\varphi_j^t : \arg\max_{c'} P_{c',j}^t = c\}$$
where $y_i^s$ is the source ground-truth label map at location $i$ (downsampled to the feature resolution, or logits upsampled — the index set $\Omega$ must be common). The kernel matrices are then
$$K_c^s\in\mathbb{R}^{|S_c|\times|S_c|},\quad K_c^t\in\mathbb{R}^{|T_c|\times|T_c|},\quad K_c^{st}\in\mathbb{R}^{|S_c|\times|T_c|},\qquad [K]_{ij}=\kappa_{\sigma_c}(\varphi_i,\varphi_j)$$
The block matrix $K_c^{mix}$, the entropy $H_2$, and the MI estimator $\tilde I_2$ are unchanged — the whole CREDA construction is agnostic to what the samples are, so Eqs. 21–22 carry over verbatim.
3.2 Per-pixel confidence weighting
The Rényi-2 uncertainty weight (Eqs. 18–19) becomes spatially indexed:
$$w_j^t = 1-\frac{\hat H_2(P_{:,j}^t)}{\log C},\qquad \hat H_2(P_{:,j}^t)=-\log\sum_{c=1}^{C}(P_{c,j}^t)^2,\qquad \tilde K_c^t = K_c^t\odot\big(\tilde w_c^t(\tilde w_c^t)^\top\big),\quad \tilde w_c^t\in\mathbb{R}^{|T_c|}$$
This has a desirable segmentation-specific interpretation: prediction entropy concentrates on class boundaries, so boundary voxels are automatically down-weighted and the alignment acts on class-interior statistics where pseudo-labels are reliable. (Optionally the weight field can be spatially pooled, $\bar w_j = \operatorname{mean}_{k\in\mathcal N(j)} w_k$, to propagate boundary uncertainty into a margin — a deviation from the paper, but mathematically trivial.)
3.3 Supervised term and total objective
The image-level cross-entropy becomes the pixel-wise cross-entropy (Dice may be added, but CE is the direct analog):
$$\mathcal L_{\text{seg}}^s = -\frac{1}{|\Omega_s|}\sum_{i\in\Omega_s}\sum_{c=1}^{C} y_{i,c}^s \log P_{c,i}^s$$
$$\boxed{\;\mathcal L = \mathcal L_{\text{seg}}^s \;-\;\lambda\sum_{c\in\mathcal C_{\text{valid}}}\omega_c\;\tilde I_2\big(K_c^s;\tilde K_c^t\big)\;}$$
with validity condition $|S_c|\ge\tau$ and $|T_c|\ge\tau$. In segmentation $\tau=2$ (as in the code) is too lax: per-class Gram statistics from a handful of pixels are meaningless; a threshold of tens of pixels, and the code's averaging over valid classes (more stable than the paper's sum when class presence varies batch to batch), are recommended. The optional class weights $\omega_c$ (e.g. inverse-frequency, or $\omega_c=1$ as in the paper) address the extreme foreground/background imbalance of dense label maps; likewise one may simply exclude the background class from the alignment sum.

4. Consequences that require new mathematics, not just re-indexing
4.1 Quadratic cost forces a sampled estimator
$|S_c|$ is no longer the batch size but the number of class-$c$ pixels in the batch ($10^4$–$10^6$). Since $H_2$ operates on the full Gram matrix, cost is $O(|S_c|^2\,d)$. The paper's estimator is, however, a pairwise-average (matrix form of the information potential $\hat V_2=\frac{1}{N^2}\mathbf 1^\top K\mathbf 1$, Eq. 8), i.e. a U-statistic over sample pairs. A subsampled version — draw $M_c$ pixels per class per batch, e.g. uniform or boundary-oversampling — estimates the same quantity and remains consistent. So the mathematically clean fix is per-class pixel quotas $M_c$, which simultaneously solves the memory problem and the imbalance problem (background no longer dominates the Gram matrices). A further alternative is a Nyström/random-Fourier-feature approximation $\kappa(x,y)\approx z(x)^\top z(y)$, turning $O(N^2)$ into $O(Nm^2)$; the entropy then acts on an approximate Gram matrix and stays differentiable.
4.2 Loss of the i.i.d. assumption
The paper's consistency argument (Section 2.3, KDE consistency) assumes independent samples. Pixels within one image are spatially correlated, so $N$ pixels are not $N$ independent draws; the effective sample size is smaller and estimator variance is higher. Mitigations, in increasing deviation from the original method:
1. Sample pixels spread across many images (pool over the batch, thin subsampling within an image) — keeps the pixel-level formulation, reduces correlation.
2. Patch-level samples: partition the feature map into patches, pool each patch to one vector (possibly class-masked average), align patch-level class-conditional distributions. Patches are "more independent" than pixels and retain local context.
3. Prototype-level samples (the conservative option): one confidence-weighted, class-masked average-pooled vector per image per class,
$$\mu_{n,c}=\frac{\sum_{i\in\Omega_n} m_{i,c}\,w_i\,\varphi_i}{\sum_{i\in\Omega_n} m_{i,c}\,w_i},\qquad m_{i,c}=\mathbb 1[\text{membership of } i \text{ in } c],$$
then build Gram matrices over $\{\mu_{n,c}\}$ across images. This restores the classification regime exactly (samples = independent images, comparable cardinalities $n_c^s, n_c^t$), at the cost of discarding intra-class spatial variability and only aligning a first-order statistic.
Choice among 1–3 is the single most important modeling decision of the adaptation; option 1 with per-class quotas is the faithful generalization, option 3 the statistically safest.
4.3 Kernel geometry: whether to include spatial coordinates
The Gaussian kernel measures Euclidean proximity in feature space only. One can inject normalized coordinates $u_i\in[0,1]^2$ via a product kernel $\kappa\big((\varphi_i,u_i),(\varphi_j,u_j)\big)=\kappa_{\sigma_f}(\varphi_i,\varphi_j)\,\kappa_{\sigma_u}(u_i,u_j)$. Recommendation: do not, for cross-domain blocks — different images have different organ/object layouts, and a spatial term would enforce layout correspondence, a stronger and usually false assumption. Feature-only kernels preserve the paper's semantics ("same class ⇒ same feature cluster, regardless of domain or position"), which is precisely the invariance segmentation needs. (Spatial terms can be defensible within a single image for self-regularization, but that is a different loss.)
4.4 Multi-scale extension
Segmentation decoders expose features at several resolutions $\ell$. The term extends linearly:
$$\mathcal L_{\text{align}}=\sum_{\ell}\lambda_\ell\sum_c \omega_c\,\tilde I_2^{(\ell)},$$
which is mathematically trivial but practically useful: deep low-resolution maps give more class-$c$ samples per batch and more semantic features; high-resolution maps give noisier pseudo-labels (hence lower confidence weights automatically — the weighting scheme already accounts for this).
4.5 Details that carry over unchanged (and why)
- Trace normalization makes the confidence weighting scale-free. $A=K/\operatorname{tr}(K)$ is invariant to a global rescaling of $K$, so $\tilde K_c^t=K_c^t\odot ww^\top$ acts only through the relative weight pattern on the eigenspectrum — the weights need no renormalization after masking to class $c$. This property is resolution- and cardinality-independent, hence survives the move to pixel samples.
- Unequal cardinalities. The block-matrix $K_c^{mix}$ already handles $|S_c|\neq |T_c|$; this becomes more important in segmentation, where per-class pixel counts differ wildly between domains (e.g. a structure visible in one domain's field of view but barely in the other's).
- Cross-block weighting asymmetry. The paper weights only the $K_c^t$ block, leaving $K_c^{st}$ unweighted. Given heavier pseudo-label noise in segmentation, weighting the cross-block columns too, $\tilde K_c^{st}=K_c^{st}\operatorname{diag}(\tilde w_c^t)$, is a justifiable symmetric generalization of Eq. 20 worth considering.
- Bandwidth. The median heuristic recomputes $\sigma_c$ per class on the pooled sampled features; keep it, since feature scale differs per class and per decoder level. Note the paper's IP derivation formally uses $\kappa_{\sqrt{2}\sigma}$ (Eq. 6) while the code uses $\sigma$ directly — trace normalization absorbs this; just treat the heuristic's output as the effective bandwidth.
- Gradient flow. As in the code, hard memberships ($\arg\max$) are detached; weights and kernels remain differentiable in $P$ and $\Phi$, so the whole term stays end-to-end trainable.

5. Summary of the adaptation
CREDA component	Classification	Segmentation adaptation
Unit of alignment	image feature $f\in\mathbb R^d$	pixel/voxel feature $\varphi_i\in\mathbb R^d$ (or patch/prototype)
Class membership	label / $\arg\max g$	label map / $\arg\max_c P_{c,i}$ per location
Confidence weight	per image (Eqs. 18–20)	per pixel: $w_i=1-\hat H_2(P_{:,i})/\log C$
Gram matrices $K_c^s,K_c^t,K_c^{st}$	over batch images	over sampled pixels, per-class quotas $M_c$
$H_2$, $K^{mix}$, $\tilde I_2$	Eqs. 9, 21–22	unchanged
Supervised loss	image CE	pixel CE $\mathcal L_{seg}$
Validity condition	$\ge 2$ samples/class	larger threshold $\tau$; mean over valid classes
Objective	$\mathcal L_{CE}-\lambda\sum_c\tilde I_2$	$\mathcal L_{seg}-\lambda\sum_c\omega_c\tilde I_2$ (optionally multi-scale $\sum_\ell\lambda_\ell$)
Bottom line: the Rényi-2 matrix-based MI core (Eqs. 9, 21–22) needs no modification — it operates on abstract Gram matrices. The real mathematical work of the adaptation is (i) redefining the sample space to dense per-location features, (ii) turning the confidence weighting into a per-pixel field, and (iii) restoring estimator validity through per-class sampled quotas (U-statistic subsampling), with patch- or prototype-level pooling as principled fallbacks when pixel correlation or compute budget dominates.

============================================================================================
PART II — CREDA-Seg v2: HARDENED FORMULATION (diagnosis + fix of the 3 pathologies)
============================================================================================

0. Preliminaries: the estimator in factorized form
Write the per-class CREDA term (paper Eq. 21, i.e. h_mix − 0.5·(h_s + h_t) in CREDA.py) in an
equivalent purity-factorized form that avoids building block matrices. For two point sets
P, Q with (possibly confidence-weighted) Gram blocks, define
$$S_2(P,Q)=\textstyle\sum_{ij}K(\varphi_i^P,\varphi_j^Q)^2,\qquad T(P)=\operatorname{tr}K(P,P)$$
$$\operatorname{ptr}(K)=\operatorname{tr}(A^2)=\frac{S_2(P,P)}{T(P)^2},\quad A=\tfrac{K}{\operatorname{tr}K};\qquad H_2(K)=-\log_2\operatorname{ptr}(K)$$
$$\Delta(P,Q)=-\log_2\frac{S_2(P,P)+S_2(Q,Q)+2\,S_2(P,Q)}{(T(P)+T(Q))^2}+\tfrac12\log_2\operatorname{ptr}(P)+\tfrac12\log_2\operatorname{ptr}(Q)$$
This is exactly $-\tilde I_2$ of the paper, in bits, but computed in O(M^2) kernel evaluations
plus O(1) reductions — no block matrix needed. All analysis below concerns Δ.

1. Root-cause analysis of the three pathologies

1.1 Why Δ collapses: it is not a proper divergence, and in the segmentation regime it
    *prefers* the Dirac solution
Claim (i) — degenerate tie. Δ(P,P)=0, including P=Q=δ_μ: the joint-Dirac configuration is a
global minimizer (Δ=0) indistinguishable from the correct match.
Claim (ii) — collapse is a strict local attractor. For a point source at 0 and a symmetric
two-point target {±ε}, with γ=e^{−2ε²/σ²}, q=e^{−ε²/2σ²}:
$$\Delta(\varepsilon)=-\log_2\tfrac{3+\gamma^2+4q^2}{8}+\tfrac12\log_2\tfrac{1+\gamma^2}{2},\qquad \Delta(0)=0,\quad \Delta(\varepsilon)>0\ \ \forall\varepsilon>0$$
Verified: +0.029 bits at ε=0.5σ, +0.346 at ε=1σ, +0.880 at ε=2σ. Spreading is penalized —
the H2-mixture penalty systematically outweighs the −0.5·H2^t dispersion reward.
Claim (iii) — worse: against a broad source, the estimator strictly prefers collapse. The
paper's intuition "Ĩ2 is a mutual information, hence ≥ 0" fails for the block-matrix
construction (the required subadditivity does not hold). Measured with a dispersed Gaussian
source (d=16, σ = median heuristic — precisely the segmentation regime, where
class-conditional *pixel* clouds are broad relative to σ):
    Δ(matched i.i.d.) = +0.009 bits,   Δ(collapsed) = −0.078 bits  (strictly lower!)
The degenerate solution achieves a strictly lower loss than the true match. This explains why
the pathology was latent in the paper's classification setting (globally-pooled image
features are compact relative to σ, so the Dirac solution is merely tied, regime (i)) but
became active in segmentation (dispersed pixel features → regime (iii)).
COROLLARY: no swap of divergences (MMD, etc.) fixes this — every D(P_s^c,P_t^c) with D=0 at
equality vanishes at the joint Dirac. The fix must constrain the feasible set (Section 2)
and anchor one side (Section 2.3).

1.2 Why target classes overlap: the objective is class-separable
L_CREDA = L_CE + λ·Σ_c(−Ĩ2,c) contains only same-class cross-domain terms. No quantity ever
measures P_t^{c1} against P_t^{c2}, c1≠c2: inter-class geometry in the target manifold is
unconstrained (the source side is separated only by CE, which the alignment gradient can
overrule — see 1.3).

1.3 Why the alignment gradient dominates
Per class, Δ aggregates O(M²) pairwise forces whose gradient scale is set by
∇_{φ_i}κ ∝ (φ_i−φ_j)κ/σ² — scale-free in feature magnitude but dense (every pixel pair
interacts), whereas pixel-CE contributes O(|Ω|) independent, bounded log-gradients. With the
median-heuristic σ shrinking as classes contract (1.1), 1/σ² *grows* as collapse proceeds — a
positive feedback loop. After unfreezing the backbone, ∇L_align (summed over C classes)
easily exceeds ∇L_seg, and pseudo-label drift moves the target the alignment chases → source
corruption (the observed source mIoU drop 0.88 → <0.41).

2. Anti-collapse: spectral entropy floor + asymmetric anchoring

2.1 The floor term
$$\mathcal L_{ac}=\frac{1}{|\mathcal C_v|}\sum_{c\in\mathcal C_v}\Big(\big[\eta-H_2(K_c^s)\big]_+ + \big[\operatorname{sg}(H_2(K_c^s))-\varepsilon_{gap}-H_2(\tilde K_c^t)\big]_+\Big),\quad [\cdot]_+=\operatorname{ReLU}$$
(sg = stop-gradient.) The target floor is adaptive (per-class, self-calibrating across
domains); the source floor is inactive in healthy training and only fires if CE loses control
of the source manifold.

2.2 Guarantee (Proposition)
H2(K) ≥ η  ⇔  tr(A²) ≤ 2^{−η}  ⇔  participation ratio
ρ(A) := (tr A)²/tr(A²) = 1/tr(A²) ≥ 2^η. Since ρ counts the effective number of
eigen-directions of the kernel operator, and rank-1 A gives tr(A²)=1:
  η>0 excludes rank-1 Gram matrices; for the strictly positive-definite Gaussian kernel,
  rank(K) equals the number of *distinct* points, hence the floor forces the class cloud to
  span ≥ ⌈2^η⌉ distinct directions  ⇒  Var(Φ_c) > 0. At the median-heuristic scale this
  means sustained dispersion at the σ-scale (σ adapts, so the floor cannot be evaded by
  global rescaling — H2 is scale-invariant under the adaptive bandwidth). Measured:
  collapse ⇒ H2=0, ρ=1.00; healthy Gaussian cloud ⇒ H2=1.40 bits, ρ=2.65.
η=1.0 bit (default) demands only ρ≥2 — deliberately mild; it amputates the Dirac basin
while leaving the healthy optimum untouched.

2.3 Asymmetric anchoring (stop-gradient)
All source-side blocks inside Δ_c are computed from sg(Φ_s): ∇_{Φ_s} L_align ≡ 0 (verified:
exactly 0.0). The target manifold chases a frozen source manifold. Within the feasible set
carved out by 2.1, the optimum of Δ_c is the true match; combined with the CE anchor on the
source, collapse is simultaneously infeasible (floors) and non-attractive (anchoring).
L_ac is an exact-penalty (ReLU) relaxation of the constraint H2 ≥ η — zero gradient when
satisfied, so it never distorts healthy training.

3. Inter-class repulsion: margin-hinged Rényi divergence in the target domain
Reuse the same estimator with the opposite sign between target class pairs:
$$\mathcal L_{rep}=\frac{2}{C_v(C_v-1)}\sum_{c_1<c_2}\big[m-\Delta(\tilde K_{c_1}^t,\tilde K_{c_2}^t)\big]_+$$
Properties (verified): for equal quotas M and two point-mass classes at kernel similarity γ:
Δ = −log2[(1+γ²)/2] ∈ [0,1] bit, attaining Δ_max = 1 bit (0.9998 at r=3σ). Hence:
- Bounded — no feature explosion (kernel saturation caps the force; contrast with unbounded
  Euclidean repulsion).
- Built-in margin — gradients vanish beyond ~3σ; already-separated classes are untouched.
  The hinge m sets an explicit feature-space margin:
  Δ ≥ m  ⇔  γ ≤ √(2^{1−m} − 1)  ⇔  r ≥ r(m) = σ·sqrt(ln(1/(2^{1−m} − 1)))
  (e.g. m=0.2 ⇒ r≥0.55σ; m=0.5 ⇒ r≥0.94σ; keep m≲0.5 since r(m)→∞ as m→1).
- Equal quotas matter: M_c=M makes Δ_max=1 bit exact and class-size-invariant.
Cheap variant (O(C²Md), means only):
L_rep^proto = (1/(C_v(C_v−1))) Σ_{c1≠c2} κ_σ(μ_{c1}, μ_{c2}), μ_c = Σ_i w_i φ_i / Σ_i w_i.
Separates prototypes but ignores within-class shape; the block-matrix version above is the
faithful one.

4. Gradient balancing and scheduling
Three independent mechanisms (defense in depth):
4a. Warmup + sigmoid ramp (repurposing the paper's own Eq. 29):
λ(t) = λ_max·s(t), s(t) = (1−e^{−δp})/(1+e^{−δp}), p = (t−T_warm)/T_ramp, δ≈10;
λ=0 for t<T_warm (source-only warmup until pseudo-labels are trustworthy).
4b. Trust-region gradient normalization (GradNorm-lite, anchored to the supervised loss).
On a reference parameter set θ* (last shared encoder block), with EMA-smoothed norms
ĝ_seg, ĝ_aux (decay 0.9):
$$\lambda_{eff}(t)=\lambda_{\max}\,s(t)\,\min\!\Big(1,\ \rho\,\frac{\hat g_{seg}}{\hat g_{aux}}\Big)\quad\Longrightarrow\quad \big\|\lambda_{eff}\nabla_{\theta^\star}\mathcal L_{aux}\big\|\le\rho\,\big\|\nabla_{\theta^\star}\mathcal L_{seg}\big\|$$
i.e. a provable cap: the total auxiliary gradient can never exceed a fraction ρ of the
segmentation gradient (up to EMA lag). L_seg stays the semantic anchor by construction.
Computed with one autograd.grad(..., retain_graph=True) per step on θ* — one extra
restricted backward, no full double backward.
4c. Layer scoping. Apply L_aux at the bottleneck / deepest decoder features only; keep
high-resolution decoder stages purely supervised. (Optional: PCGrad-style projection — if
⟨g_seg, g_aux⟩ < 0, project g_aux onto the normal plane of g_seg; stronger but costlier
and noisier per-step.)

5. Complete objective
$$\mathcal L_{total}=\mathcal L_{seg}^s+\lambda_{eff}(t)\Big[\,\mathcal L_{align}+\beta\,\mathcal L_{ac}+\gamma\,\mathcal L_{rep}\,\Big]$$
$$\mathcal L_{seg}^s=-\frac{1}{|\Omega_s|}\sum_{i\in\Omega_s}\sum_c y_{i,c}^s\log P_{c,i}^s\ (+\,\text{soft-Dice});\qquad \mathcal L_{align}=\frac{1}{|\mathcal C_v|}\sum_{c}\Delta\big(K_c^s(\operatorname{sg}),\ \tilde K_c^t\big)$$
with per-class quota sampling (M pixels/class, min count τ), per-pixel confidence weights
w_i = 1 + log2(Σ_c P_{c,i}²)/log2 C, K̃^t = K^t ⊙ wwᵀ, median-heuristic σ_c (detached), and
L_ac, L_rep as in Sections 2–3.
Default hyperparameters: M=128, τ=8, η=1.0 bit, ε_gap=0.25 bits, m=0.2 bits, β=1, γ=0.5,
λ_max=1, ρ=1, δ=10, warmup 1000 steps, ramp 9000 steps, EMA decay 0.9.
Complexity: alignment O(C·M²·d); repulsion O(C_v²·M²·d) via one batched cdist; everything
fp32 under autocast-off (AMP-safe).

6. PyTorch module
Full tested implementation: SegCREDA.py (same folder). Structure:
- forward(feat_s, logits_s, labels_s, feat_t, logits_t) -> (total, parts)
    · pixel-CE (+ optional soft-Dice) as L_seg in the caller's autocast context
    · CREDA core in fp32 with autocast disabled (AMP-safe)
    · per-class quota sampling (min_samples, replacement when n_c < M)
    · median-heuristic σ per class (detached)
    · Δ_c via the purity-factorized form (Section 0), source blocks stop-grad
    · entropy floors: [η − H2_s]_+ and [sg(H2_s) − ε_gap − H2_t]_+
    · batched cross-class repulsion: one cdist (C_v,C_v,M,M) + ReLU(m − Δ_ij) over i<j
    · total = L_seg + float(lambda_eff) · L_aux   (float(): lambda_eff is a scheduled
      scalar, not a graph node — using the buffer tensor would break backward when
      update_lambda mutates it in place between forward and backward)
- update_lambda(loss_seg, loss_aux, ref_params)  # call AFTER forward, BEFORE backward
    · λ=0 during warmup; EMA gradient norms on ref_params via autograd.grad
      (retain_graph=True); λ_eff = λ_max · s(t) · min(1, ρ·ĝ_seg/ĝ_aux)
Usage:
    crit = SegCREDALoss(num_classes=C)
    ref  = list(model.encoder.layer4.parameters())   # reference params
    for batch in loader:
        total, parts = crit(feat_s, logits_s, labels_s, feat_t, logits_t)
        crit.update_lambda(parts["loss_seg"], parts["loss_aux"], ref)  # before backward
        total.backward()
        optimizer.step(); optimizer.zero_grad(set_to_none=True)
Diagnostics returned in parts: loss_align, loss_anti_collapse, loss_repulsion,
h2_source_mean, h2_target_mean, delta_align_mean, delta_repulsion_mean, lambda_eff,
n_valid_classes, n_rep_pairs.

7. Verification summary (executed on the shipped module)
- Basic forward/backward: finite loss; gradients flow to target features and source logits.
- Asymmetric anchoring: ||∂L_aux/∂feat_s|| = 0.000000 (exact), ||∂L_aux/∂feat_t|| > 0.
- Collapse detection: collapsed class features ⇒ H2_source_mean = 0.0000 bits and
  L_anti_collapse = 1.0 (= η); healthy run ⇒ 0.0 (floors inactive).
- Estimator negativity (pathology, standalone): Δ(matched) = +0.0085 bits vs
  Δ(collapsed) = −0.0781 bits — the estimator flaw is real, and is neutralized by the
  floors + anchoring (Sections 2–3).
- Repulsion: separated classes ⇒ Δ_rep = 0.998 bits ⇒ hinge = 0 (no force);
  overlapped classes ⇒ Δ_rep = 0.053 bits ⇒ L_rep = 0.147 (active repulsion).
